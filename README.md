## What it does

- **PDF Invoice Generation** - Fill in customer details, line items, and hit Save & Download. A pixel-perfect PDF is generated client-side and downloaded instantly.
- **Auto Bill Numbering** - Bill numbers are auto-generated by querying the latest entry in Supabase, ensuring unique, sequential IDs across sessions.
- **Cloud History** - Every invoice is saved to Supabase Storage. Browse, re-download, or delete past invoices from the Invoice History panel.
- **Mobile-Responsive** - The entire UI adapts to mobile with card-based layouts for both the items table and invoice history.
- **Passcode Protected** - A client-side passcode gate prevents unauthorized access to the invoice generator.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gloooomed/Invoice-Generator.git
cd Invoice-Generator
npm install
```

### 2. Configure Supabase credentials

`supabase-config.js` is **gitignored** - create it locally from the template:

```bash
# Windows (PowerShell)
Copy-Item supabase-config.example.js supabase-config.js

# macOS / Linux
cp supabase-config.example.js supabase-config.js
```

Open `supabase-config.js` and replace the placeholder values:

```js
window.SUPROAN_SUPABASE_URL      = 'https://YOUR_PROJECT_REF.supabase.co';
window.SUPROAN_SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

Find these values at: **Supabase Dashboard → Project Settings → API**

> ⚠️ Never commit `supabase-config.js`. Only `supabase-config.example.js` (with placeholder values) belongs in version control.

### 3. Supabase project setup

1. Create a Supabase project.
2. Run `supabase/schema.sql` in the Supabase SQL editor.
3. Deploy the Edge Functions:

```bash
supabase functions deploy save-invoice
supabase functions deploy delete-invoice
supabase functions deploy create-invoice-download
```

The service role key is used only inside Supabase Edge Functions through the built-in `SUPABASE_SERVICE_ROLE_KEY` environment variable. Do not put it in frontend files.

### 4. Run locally

Open `index.html` with any local server (e.g. VS Code Live Server).

## Usage

1. Open the app and enter the passcode.
2. Fill in customer name, phone, address, bill date, and line items.
3. Click **Save & Download PDF** - the PDF downloads locally and is saved to Supabase.
4. The form auto-resets and the next bill number is generated automatically.
5. Previous invoices appear in **Invoice History**, with download and delete actions.

## Contributing

Contributions are welcome! Here's how to get involved:

### Prerequisites

| Requirement | Version | Notes |
|---|---|---|
| [Node.js](https://nodejs.org/) | v18+ | LTS recommended |
| [Git](https://git-scm.com/) | Any recent | For version control |
| [Supabase Account](https://supabase.com/) | - | Free plan is sufficient |
| [Supabase CLI](https://supabase.com/docs/guides/cli) | Latest | For deploying Edge Functions |

### Steps

1. **Fork** the repository
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Make your changes** and commit with a clear message:
   ```bash
   git commit -m "feat: add your feature description"
   ```
4. **Push** to your fork:
   ```bash
   git push origin feat/your-feature-name
   ```
5. **Open a Pull Request** against `main` and describe what you changed and why.

### Guidelines

- Keep PRs focused - one feature or fix per PR.
- Follow the existing code style (vanilla JS, CSS custom properties, semantic HTML).
- Test on both desktop and mobile before submitting.
- For larger changes, open an issue first to discuss the approach.
